МАТ-БУМ! 3 «Побег из сферы» — техно-демо 0.1.0
================================================

Открой index.html через локальный сервер (уже может быть на порту 8765).

Быстрый прогон
--------------
1. ИГРАТЬ → выбери любую сферу.
2. Ты внутри стеклянной капсулы (бронзовый UI).
3. Три тапа по центру — капсула трещит и разбивается.
4. Собирай тройки пластин по формуле слоя (как в MB2).
   Порядок слоёв: + → − → × → ÷ (от центра наружу).
5. Удерживай «👁 СНАРУЖИ» — вид снаружи (отпускаешь — снова внутри).
6. После 4-го слоя — тапы по внешней мембране → приз.

Геометрия
---------
  R капсулы     40
  слой +        72   (72 плитки)
  слой −       104
  слой ×       136
  слой ÷       168
  мембрана     200
  космос         ∞

Что сознательно упрощено в демо
-------------------------------
• Цепочные формулы X=A+B+C — на лейблах; валидация пока 3-пластинная как в MB2
  (полный генератор 4-чисел — следующий спринт).
• Лучи-витражи и анимация «слой выныривает 1.5с» — заготовки, не финал.
• Один макет сферы, без полного пакета текстов черновика.


Обновление пропорций (planet scale)
-----------------------------------
• Радиусы слоёв: 120 / 168 / 220 / 280, капсула 58, мембрана 340
• Плитки крупнее (plateK 0.97), FOV 72° — ощущение «внутри планеты»
• Светящийся каркас, следующий слой просвечивает
• Кнопка «ТИП ×»: выбери 1 плашку → убрать все того же типа (цифра+цвет)
• Края окна растворяются (CSS mask), вращение легче


Спринт продолжения
------------------
• Лучи-витражи сквозь снятые плитки (additive, ≤24 линий)
• Анимация смены слоя 1.5с — оболочка выныривает из глубины
• Звёзды на мембране (POINTS)
• Ядро-ориентир в центре (глубина планеты)
• ТИП ×: 1 плашка или несколько одного типа; клавиша T
