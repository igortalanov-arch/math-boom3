# Мат-Бум! 3 — Побег из сферы (техно-демо 0.3.0)

Ракурс **гигантской арены**: камера высоко и сзади, смотрит вниз в чашу.
Ближние плитки огромные, дальние — как муравьи. Медленное величественное вращение.

## v0.3.0
- Камера арены (Real Steel bowl), FOV 52°
- Радиусы 220 / 320 / 440 / 580, мембрана 720
- Атмосферный fog, дрейф вращения, светящийся каркас
- Цепочки X=A⊕B⊕C, ТИП ×, лучи, звёзды

python3 -m http.server 8765
