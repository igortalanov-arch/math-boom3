# МАТ-БУМ! 3 «Побег из сферы» v1.0.4 — пакет скриншотов для Яндекс Игр

20 скриншотов: 5 сцен × (десктоп + мобильные) × (RU + EN).
Каждый кадр — реальный кадр игры (headless-рендеринг v1.0.4), не мокап.

## Структура
```
ru/desktop/   1920×1080 (16:9)  — для поля «Десктоп»
ru/mobile/    1080×1920 (9:16)  — для поля «Мобильные» (портрет)
en/desktop/   1920×1080
en/mobile/    1080×1920
```

## Соответствие требованиям черновика Яндекс Игр
(https://yandex.ru/dev/games/doc/ru/console/add-new-game/draft, раздел «Скриншоты»)

| Требование | Статус |
|---|---|
| Десктоп — только альбомная, 16×9 | ✓ 1920×1080 |
| Мобильные — 9×16 (портрет, соответствует ориентации «Портретная» или «Любая») | ✓ 1080×1920 |
| Размер от 1280 до 2560 px по длинной стороне | ✓ |
| Формат JPEG или 24-разрядный PNG | ✓ PNG, 24 бита (RGB) |
| Не менее 2 скриншотов на каждую платформу | ✓ по 5 |
| Реальный геймплей занимает ≥70% изображения | ✓ кадры целиком — интерфейс игры |
| В игре нет надписей «Яндекс Игры», видимых игроку (по README проекта) | ✓ снимки сделаны в гостевом режиме, без SDK-элементов |

| 01-menu | Главное меню (на десктопе — мини-музей и рекорды по бокам) |

Для промо в кадры загружен прогресс игрока: 6 из 10 сфер собрано,
рекорды 2480–4180, всего 19200 очков.

## Загрузка в Консоли
1. Черновик игры → шаг 6 «Материалы для продвижения» → «Добавьте скриншоты».
2. В выпадающем списке выберите тип устройства: **Десктоп** → загрузите
   5 файлов из `ru/desktop` (на вкладке RU) и из `en/desktop` (на вкладке EN).
3. **Мобильные** → 5 файлов из `ru/mobile` / `en/mobile` аналогично.
4. Не загружайте десктопные и мобильные кадры в одно поле — тип устройства
   выбирается отдельно.

   заменён на `Pick A B C`. Рекомендуется исправить на `T('drag')`

2. **assets/figures/01–10.jpg**: в изображениях фигурок «запечены»

   подставить в сборку, подписи дублируются текстом интерфейса).

## Как сделаны кадры
- Playwright + headless Chromium, WebGL (SwiftShader).
- Десктоп: viewport 1920×1080, dpr 1.
- Мобильные: viewport 432×768 CSS px, deviceScaleFactor 2.5 → 1080×1920
  (реальный телефонный режим игры: HUD сверху, управление снизу).
- SDK (/sdk.js) заблокирован — гостевой режим, как на локальном запуске.
